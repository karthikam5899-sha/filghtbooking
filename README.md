# SkyBook - Flight Booking UI

A responsive flight booking front-end built with React, Vite, Tailwind CSS, Framer Motion, Lucide React and Recharts.

## Features

- Flight search form
- From/To city swap animation
- Date picker
- Passenger/class dropdown
- Animated validation
- Flight result cards
- Skeleton loading
- Airline filter
- Price filter UI
- Sort functionality
- Flight details modal
- Passenger step form
- Animated progress stepper
- Interactive seat map
- Seat hover and selected animations
- Payment method selection
- 3D card flip
- Booking confirmation
- Responsive design
- Micro-interactions

## Requirements

Node.js 18+ recommended.

## Install

```bash
npm install
```

## Start

```bash
npm run dev
```

Then open:

http://localhost:5173

## Production build

```bash
npm run build
```

## Preview production build

```bash
npm run preview
```

## Notes

This is a front-end demo using mock flight data. Payment and booking operations are simulated and should be replaced with secure backend/API integrations for production use.
